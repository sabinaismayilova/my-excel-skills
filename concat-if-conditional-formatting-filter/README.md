# CONCAT, Text to Columns, IF Logic, Conditional Formatting & Filtering

A multi-part practice workbook covering text splitting and joining,
conditional logic, visual formatting rules, and dataset filtering —
applied to HR decision-making and a real telecom subscriber dataset.

## What's inside

**Concat and Delim sheet:**
- Text to Columns used to split a full name string (e.g. "Ms. Sevinc
  Muradova") into separate Title, First Name, and Last Name columns
  based on a space delimiter
- The reverse operation: CONCAT vs. the `&` operator, rejoining a
  title, first name, and last name into one string — two different
  methods producing the same result

**IF sheet:**
- Nested logic to decide whether to renew an employee's contract, based
  on two different criteria: revenue generated vs. salary, and actual
  vs. required work hours

**Cond. Formatting sheet:**
- Multiple conditional formatting rule types applied to the same data:
  Top 20%, custom value thresholds, Data Bars, and Icon Sets
- A "New Rule" icon-set formula comparing salary across two years and
  flagging the direction of change with arrows

**Filter sheet:**
- Ten different filter conditions applied to a real telecom subscriber
  dataset (Zakir MMC), covering exact match, greater-than-or-equal,
  range, and year-based conditions — using COUNTIFS to return the
  subscriber count matching each condition

## Skills demonstrated

- Text to Columns for splitting delimited text into separate fields
- CONCAT vs. `&` for rejoining text — the inverse operation
- Nested IF statements for rule-based decision-making
- Choosing the right conditional formatting rule type for the question
  being asked (ranking, thresholds, magnitude, direction)
- COUNTIFS with different operators (`=`, `>=`, range, text match) across
  a real multi-column dataset
