# Text Parsing, Data Validation & Cross-Tab Summary Tables

A practice workbook covering text extraction from IDs, data type
validation, keyword search, and pivot-style summary tables — applied to
a 10,000-row retail order dataset with intentionally malformed data.

## What's inside

**Order ID parsing:**
- Extracting the year embedded in each Order ID (e.g. "CA-2016-152156")
  using SEARCH to locate the delimiter and MID to pull out the year,
  then flagging each order as belonging to 2016 or not

**Date cleanup:**
- The Ship Date column arrives in a broken/inconsistent format. Fixed
  by using Text to Columns to split the date into separate Year, Month,
  and Day fields, then rebuilding a proper date value with DATE() —
  rather than relying on Excel's automatic date parsing, which fails
  silently on malformed input

**Data validation:**
- A "Number Check" column using ISNUMBER to flag which values in the
  Quantity column are genuinely numeric

**Keyword search:**
- A "Table_check" column using SEARCH + ISNUMBER to detect whether the
  word "Table" appears anywhere within each Product Name — a
  substring match, not an exact match

**Cross-tab summary tables:**
- Two summary tables (Total Sales Volume, and Order Count) built with
  SUMIFS/COUNTIFS, filtered to only orders whose product name contains
  "Table," broken out by Segment (rows) and Ship Mode (columns)
- Row and column labels for each table were generated by copying the
  Segment and Ship Mode columns and using Remove Duplicates to get a
  clean, accurate list of unique values — rather than hardcoding
  category names by eye

## Skills demonstrated

- Extracting structured information (a year) from an ID string using
  SEARCH + MID, and validating it with a text-based IF comparison
- Recovering usable dates from malformed source data via Text to
  Columns + DATE(), instead of trusting automatic date parsing
- ISNUMBER for data-type validation
- SEARCH + ISNUMBER for substring/keyword detection within longer text
- SUMIFS/COUNTIFS with multiple conditions (category, sub-category, and
  a keyword flag) across a cross-tabulated table layout
- Using Remove Duplicates to derive accurate table headers directly
  from the data, rather than assuming or hardcoding category values
